# All modules — one review table

**Shipped** = AudioBrain now. **Proposed** = named extraction/design candidate. **Source only** = present in Morphazoid, outside the current AudioBrain node catalog. **Exploratory** = an interface or capability still to design. These labels describe availability; the Type column describes the job.

Full instruments and their parts both appear. Shipped ports summarize AudioBrain; shader/Composer ports summarize their source declarations. Other interfaces are marked **Proposed**. Controls are a short review list, not a complete parameter specification. Physical parts require a compatible coupled solver; components and runtime internals need not become public nodes. Source availability does not establish AudioBrain feature parity.
